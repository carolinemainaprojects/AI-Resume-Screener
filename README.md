AI Resume Screener

An AI-powered resume screening application that analyzes candidate resumes against a specific job description and provides an intelligent assessment of the candidate's suitability for the role.

## 🚀 Live Demo

[AI Resume Screener](https://ai-resume-screener-dhhsbmjhkddjpz6tmjery3.streamlit.app/)

## ✨ Features

* 📄 Upload resumes in PDF format
* 🤖 AI-powered resume analysis using Google Gemini
* 📊 Resume scoring
* 🎯 Job-match scoring
* 💼 Suitable role recommendations
* ⭐ Top skills identification
* ✅ Matching skills identification
* ❌ Missing skills identification
* 💪 Strengths analysis
* ⚠️ Weaknesses analysis
* 💡 Personalized improvement recommendations
* 👤 Candidate summary
* 📥 Downloadable screening report

## 🔄 How It Works

**Resume PDF → Text Extraction → AI Analysis → Job Matching → Candidate Evaluation → Screening Report**

The application extracts information from the uploaded resume and compares it with the provided job title and job description. Gemini AI then evaluates the candidate and generates a structured screening report.

This application can help:
